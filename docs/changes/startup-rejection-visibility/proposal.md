# 启动拒绝可见性

区分准入前拒绝与已准入请求失败，并保留固定的账号路由拒绝原因，便于定位部署后短时 503。

- 每日汇总复用既有准入前诊断表和业务日、Key、模型、保留期规则。首页显示已记录的准入前拒绝，原请求数、错误率和用量口径沿用。
- 应用日志保留续接来源不可用、账号暂不可用、账号冷却、凭证刷新等固定类别。公开错误、认证和派发规则沿用。
- 通过本地重建数据服务、保留账号和账本测试跨重启续接边界。线上一组历史 503 的具体原因仍需新增诊断证实。

依据 [协议](../../reference/specs/protocol.md) 与 [管理面](../../reference/specs/control-plane.md) 验证。不新增持久字段，无数据迁移，可回退至上个版本。
