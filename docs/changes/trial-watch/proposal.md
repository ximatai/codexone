# 试运行跟踪

依据 [A10/A13](../../specs/control-plane.md) 与 [O08/O12/O13](../../specs/operations.md)，增加独立 Python 标准库巡检工具，不改变网关 API。私有外置配置控制 transport 与原样回滚命令；仅收集聚合统计及安全名称，不持久化凭证或原始日志。

以日账本快照差分统计准入和失败（取消剔除），首次建立基线；迟到结算计入发现区间。自动回滚仅依据成功探测中的连续就绪失败或连续容器非运行，不依据 transport 失败。回滚先持久化一次性标记，再执行，结果未知不重试。状态目录加独占锁。

验收：合成传输故障/超时、阈值边界、幂等回滚、摘要、秘密不落地，以及真实本地合成网关探测。操作说明见 [使用文档](../../development/trial-watch.md)。
