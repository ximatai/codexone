# 在用量与诊断展示拒绝请求的模型和推理档位

通过 Key 认证后被模型或推理档位校验拒绝的 Responses 请求，保存可信目录确认的模型及有界档位。用量明细复用现有列，在请求详情和拒绝汇总中展示模型不可用、档位未提交、无效、越界或使用旧字段。只有旧顶层字段导致拒绝时才展示其值，其他拒绝使用标准字段。

拒绝记录不进入执行账本，用量、准入和客户端错误不变。旧行保留原值，缺失项显示未记录。字段沿用拒绝诊断的保留上限。schema v19 为拒绝记录增加可空的一列，固定枚举保存缺失、无效或已知档位。schema v18 通过已有备份与迁移入口自动升级。旧程序不能直接打开 v19，需要独立恢复兼容备份并遵守账本核对规则。
