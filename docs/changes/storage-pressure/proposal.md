# 低磁盘保护与必要运行观测

依据 O02/O05/O07/O09/O14，补齐物理空间、WAL/读事务和可选工作的分级门禁。主库寿命内持同一实例锁拥有私有实际分配的结算储备文件；正常启动/空间恢复时补充，低空间只由既有执行绑定、结算及刷新收尾使用。每次写准入在 writer 队列复核真实可用空间和 WAL，先停止报表/诊断/观察/普通管理写，再拒绝新 intent，保留只读管理、live 和关键收尾。阈值带滞回，空间恢复不删除 unknown/账本或赠送额度；真满/不可写仍可能令核心失败并依赖已有 intent 恢复，不能保证外部进程抢占所有空间时仍可写。

Runtime 单一有界周期 owner 触发采样和非阻塞 checkpoint；同一 writer 串行空间变更，队列容量与最终化保留不弱化。报表低水位拒绝并取消已有扫描，避免持续钉住 WAL；监测文件/WAL/空闲/储备、checkpoint 进度/busy、writer 队列及延迟、当前报表、进程 RSS/FD。认证管理只读端点返回固定字段，无路径/主体/正文；健康读取缓存，不在网络 event loop 做文件 I/O。没有正文恢复缓存可停，M5 缺口保持。

离线备份/迁移/恢复/再加密在新写前预算源/目标空间并在复制/页边界复核，备份不能吃掉核心安全余量；失败不发布完成标记/新目标，保留原库及部分维护屏障。现有 v8 schema/授权/信封不变，不自动删除核心责任或物理备份。

验收：主 Agent 定向测试分级/滞回、储备实际分配及释放、队列内最后复核、报表中断与长读 WAL、SQLite 写失败/重启 intent；真实隔离 Linux 有界 tmpfs 低水位/ENOSPC、已准入关键收尾、readiness/live/认证观察和备份空间不足。macOS 不填满宿主磁盘，注明注入和实际文件验证边界。提交后集中 subagent review、主 Agent 修复与阶段出口跨平台完整验证；不做真实账号调用、部署或容量完成声明。
