# 管理会话与 Key 界面

## 目标与边界

在已交付的 Key 原子命令上实现 I07、A01/A02/A06 的管理会话与可操作界面部分。普通数据 Key 不能登录管理台；管理员用私有文件注入的独立高熵凭证登录，一次性输入不写浏览器存储。Key 的创建、禁用、轮换、模型范围和五类本地治理限额可由界面操作，旧 revision 冲突可解释并刷新，不默默覆盖。

禁用的 Key 应能先轮换凭证、保存新凭证后再显式启用；轮换保留当前 enabled 状态，不要求短暂激活可能已泄露的旧凭证。该动作仍占普通审计额度，不得动用真实禁用的预留。

仍保留 M2 Desktop UI/恢复契约缺口；此处“浏览器管理界面”不等于 Codex Desktop 验收。账号 OAuth/池、订阅额度、完整用量查询及图片开关在各自切片交付，不能把 Key 页面当整个 M3 完成。此切片不启用真实账号或外部生成调用。

## 安全与资源

登录创建有界内存管理 session：安全随机 token，只保存不可逆验证值；Cookie 为 HttpOnly/Secure/SameSite=Strict、限定路径/期限，重启失效。状态变更同时检查精确可信 Origin 与 CSRF 证明；不由任意 Host/转发头推导可信 origin，不开 CORS。现有无浏览器 Bearer 管理保留独立验证，混合凭证拒绝；不让 SPA 每次携管理员原文或将其保存到 localStorage/sessionStorage。登出清除会话及前端一次性数据 Key。

明确配置公开管理 origin；loopback 直连可由实际监听地址确定，反代必须使用显式配置。登录/会话/Key 请求共用有界管理入口；session 数量、期限、清理和请求容量有明确 owner，不用永久背景 Task。会话失败/过期显示登录状态，网络错误、CAS 冲突和容量失败分别反馈；未定义浏览器无声重试变更。

可选加载预先构建的 SPA，入口只提供明确的 index 和有限 JS/CSS 静态资产；文件/数量/总字节有界、拒绝符号链接与未知路径，不把 data/secret 目录变成文件服务器。静态页面有 CSP/frame/referrer 保护；管理 API no-store，数据 Key 仅创建/轮换后一次显示，关闭后不能找回。前端由现有 React/TS/Vite 实现，优先大屏，不引入仅为页面布局需要的新框架。

## 验收

真实 API/socket 验证登录错误、Cookie 安全属性、CSRF/Origin/Host、过期/登出/重启失效、混合凭证拒绝、session/请求容量和静态路径隔离。真实 Chrome 接临时网关/合成上游，从登录开始创建 Key、按模型选择/配置限额、禁用、轮换、一次性秘密关闭和失败重试；用实际数据面证明新 Key 的目录/执行与权限一致。浏览器测试使用独立临时上下文，不读取个人 Cookie/客户端配置，截图只显示公开合成数据，主 Agent 查看截图并操作复盘。可操作成果后 subagent review，主 Agent 修复复验。

## 数据与回退

复用 Key schema 与审计，不改变账本或对象归属。新增配置为可选；无静态资产时保留管理 API 与已有健康契约。会话不持久化，不进入备份；管理员凭证轮换/服务重启使内存会话失效。范围不含远程部署、发布或旧服务替换。
