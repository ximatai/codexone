# 统一服务器资源使用率

管理员扫视概览时，三个环越满均表示相应资源使用比例越高。CPU 环下展示 1 分钟负载原值（如 `0.47`），缺测时省略。内存和数据盘环下展示剩余容量。三个资源的一小时趋势均按百分比展示，CodexOne 进程 RSS 按 MiB 展示。

## 验收与兼容

沿用现有 HTTP 与 WebSocket 存储快照，内存使用率按各时点主机总量折算，数据盘使用率按当前卷总量折算。未知样本保留缺口。无需更改采样、schema 或安装配置，回退前端即可恢复原展示。
