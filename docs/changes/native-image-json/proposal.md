# 原生图片生成保留非流式请求

同一订阅账号的对照已验证上游非流式 JSON 返回 PNG 和输入、输出用量。本轮让网关沿客户端选择请求上游，消除普通非流式生成的固定 SSE 转接。

- 原生生成的省略 `stream` 和显式 `false` 保持原请求，向上游声明 `Accept: application/json`。
- 普通图片生成若收到上游主动返回的 SSE，仍可在同一次响应内按现有规则聚合。显式 GIF/SVG 和未知格式维持各自媒体类型边界。编辑、流式客户端和模型权限沿现有契约。
- 保持既有上传后首响应期限、进展期限、完整 JSON 校验、用量证据、取消和不重放约束。

以 [P10、P27 和原生图片约定](../../reference/specs/protocol.md) 为准，通过真实 socket 验证延迟响应、正文进展、断开、畸形结果与账本。候选线上复用固定 Key 核验。无 schema 迁移，回退使用同 schema 的上一候选及切换前检查点。
