# 长任务与可信模型选择闭环

依据P11/P13/P14、I17与兼容取舍，主Agent实现可维护的正常长任务与受信profile导入，不接真实订阅/在线发现、不扩展工具服务或M5缓存。

执行总期限缺省600秒，可显式1—1800秒；首响应默认30秒、业务进度空闲默认60秒，显式值分别1—120/1—300秒且不超过总期限，省略时取总期限的较小值。HTTP/SSE、桥接/native WS与compact统一快照；SSE注释/本地保活/WS ping不延长业务进度，重复created/in_progress只启动首事件阶段，不持续续期；JSON正文按有效负载字节推进且保留总期限/大小边界。接入上传、建连、下游写入和WS连接寿命仍独立有限。

可信profile使用管理员0600本地版本化快照，记录source/revision/采集时间/客户端版本/模型指导。启动先验证整份快照，选择配置已声明模型的profile；不会新增模型、价格、权限或URL。显式内联catalog完整覆盖快照catalog，不局部混合指导。来源文件故障拒绝新启动且保留原文件，运行实例保有已加载快照；标明陈旧，不伪造在线更新。后续在线发现单独立项。

验收：实际socket持续单次超过120秒、首响应/无进度/心跳/总期限/取消/不重放与资源归还；真实CLI从同一快照选模并采用指导；畸形/缺模型/过期标记/权限/链接/覆盖及价格/Key边界回归。主Agent定向实现后提交、集中review/修复，出口完整macOS后端、受影响Linux优化程序与实际CLI验证。没有前端产品改动时不重复浏览器全集。当前冻结候选保留，后续产物使用新标识。
