# 在线备份与日志轮转

保留该变更的范围与未完成验收入口。

## 范围与契约

使用独立备份目录、SQLite Backup API 和完整 bundle 自检；启动 10 分钟后首次，轮次结束等待 24 小时，保留 7 份。失败不删旧备份、不妨碍核心结算。Compose 保持独立卷与有界日志。

已实现行为以[正式说明](../../operations/snapshot-maintenance.md)为准；此提案保留到未完成检查收敛，不作为已发布或实际提供者兼容的证明。

## 验收

核对[任务清单](tasks.md)中未勾选项，覆盖真实外部接口、错误、取消、超时和部分失败。合成测试不替代对应客户端、Linux 镜像或实际提供者验证；真实账号操作需由操作者确认授权与额度。
