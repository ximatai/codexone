# 上游 WS 关闭处理

保留该变更的范围与未完成验收入口。

## 范围与契约

上游固定身份连接关闭后停止新 create，结束当前执行责任并关闭下游；归还连接、lane 和正文资源，不自动重连或换账号重放。

已实现行为以[正式说明](../../reference/specs/protocol.md)为准；此提案保留到未完成检查收敛，不作为已发布或实际提供者兼容的证明。

## 验收

核对[任务清单](tasks.md)中未勾选项，覆盖真实外部接口、错误、取消、超时和部分失败。合成测试不替代对应客户端、Linux 镜像或实际提供者验证；真实账号操作需由操作者确认授权与额度。
