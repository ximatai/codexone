# 协议容量与图片能力对齐

明确正文容量与扩展图片格式的协议边界、验收和回退。

## 已确认的业务边界

大正文争用共享容量时短时等待，超时返回 503；只等待容量，不重放已派发请求。GIF/SVG 默认允许尝试，沿现有图片生成权限及图片模型范围；不另设格式开关或逐账号确认配置，由提供者决定实际支持。SVG 使用上游默认编写模型，暂不允许客户端指定 svg.model。公开 API 文档不代表订阅内部端点实际支持。

## 设计与规范影响

- 对照 [协议正文预算](../../reference/specs/protocol.md)及[职责约定](../../architecture/ownership.md)，保留单正文 32 MiB、免预留阈值 8 MiB、共享预算放宽至 64 MiB（可容纳两个 32 MiB 正文）。HTTP 已知长度正文及 WebSocket 首帧在读取大正文前最多等待 5 秒；全局最多 4 个空 lease FIFO 等待者；增量及控制申请不加入该队列。等待仍受原读取期限、取消和连接关闭约束。增量正文已持有部分内容时继续立即拒绝，避免相互持有容量等待。
- WebSocket 等待由连接事件循环拥有，暂停主动读取，已在途输入最多暂存 256 KiB；超出提前返回容量错误并丢弃该消息。超时、断连和移除均释放等待票据，已完成正文的 lease 仍由执行 owner 持有。
- 图片生成不再对非流式格式强制 SSE。移除逐账号格式确认及额外路由范围，所有入口继续受图片启用与模型授权约束；普通 SVG 沿图片生成配置，显式选择 svg.model 明确拒绝。已知无效格式/流式组合在派发前拒绝，其他能力交由提供者判定。普通图片现有默认行为保持兼容。
- 诊断只增加固定枚举，不采集正文、密钥或账号身份；不根据断连自动重试。

## 验收

真实传输边界测试覆盖等待后成功、排队上限、超时、取消、断连、在途输入上限、分片增长拒绝及下一消息恢复。图片测试覆盖默认启用、图片权限与模型隔离、独立 SVG 模型选择拒绝、格式与流式组合、普通格式回归及用量结算；容量测试覆盖两个最大正文并存、第三个排队及释放。合成提供者不代表实际订阅兼容；真实能力仍需受控在线测试验证，不将合成结果描述为已支持。

## 排除与迁移

不继续扩大单请求上限，不实现透明重放、steering 或文件上传新接口，不改变持久恢复屏障，不自动付费探测账号能力。无数据库 schema 迁移；没有新增格式配置或持久能力字段；回退恢复 48 MiB 预算及原版格式传输，可能重新出现容量拒绝。线上部署和付费能力探测在本地与 CI 验收后另行准备。
