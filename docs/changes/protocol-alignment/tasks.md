## 复盘后发布前补齐

- [ ] 拆分共享正文预算与每连接 WS 队列容量：共享保持 64 MiB，入站与请求调度队列各保持 48 MiB。
- [ ] 分离图片输入/输出校验，使 Responses 图片工具可接收真实合成 GIF/SVG 输出；参考图输入仍限 PNG/JPEG/WebP。
- [ ] 补齐 Responses 顶层及图片条目独立 svg_usage 的 partial/unknown 保护，保留已观察用量。
- [ ] 用真实格式字节覆盖 Images 与 Responses 的 JSON/SSE/WS；不再以 PNG 返回代替 GIF/SVG 输出验收。
- [ ] 补混合大正文与接近 8 MiB 请求/多 lane 积压的 Linux 内存、拒绝及关闭释放验证。
- [ ] 修复后重新完成相关验收与评审，再恢复合并发布；准备经 CI 核验的候选镜像与回退材料。
- [ ] 经维护者确认模型和调用次数后，复用既有验收 Key 做受控真实 GIF/SVG 调用；记录真实格式、用量与未知责任，再完成发布验收。

既有合成测试通过不覆盖上述缺口，证据与局限见[验证记录](verification.md)。当前保持草稿，不合并部署。
