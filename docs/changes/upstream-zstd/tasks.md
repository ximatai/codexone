## 提交 4：真实进程合成接口矩阵

全部通过 socket 操作网关 binary 与 loopback 假上游；每项核对发送次数、同一 attempt/账号、最终账本/健康、资源回收与诊断，不能用 helper 成功替代。

| 场景 | 必须验证 |
| --- | --- |
| 正常 JSON/SSE；阈值下/等于/超过；off | 压缩门槛与头/framing；同一合成最终编码在明文及解压后逐字节一致；无 checksum、未知原始大小、单帧结束；阈值非法配置拒绝启动。 |
| 已知长度明文与 chunked zstd；慢读/不读 | 慢上传超过 first 仍可成功；上传后静默触发 first；排队/不读/CPU 工作受总期限，不得把编码完成当上传完成；AHC 缓冲边界有明确说明。 |
| 取消/停机 | 初始化前、worker 排队/执行中、分块间、尾帧待消费、EOF 后、下游静默断开；取消与 EOF/超时同刻竞争；无悬挂 job、双重释放、提前 free 或迟到 sent。 |
| 断流与部分响应 | 上传一部分即断、收完整帧但不回头、200 后无终态、部分事件后断；无重放，未知/部分用量不补零，迟到错误不覆盖可信证据。 |
| 上游拒绝 | 完整上传和上传未完时分别返回 400/415，含空/畸形错误正文；400 仅一次；压缩请求 415 同账号、同 attempt 复用编码 Data 明文重发且仅一次；重发后 415 不重发；无事件时按 U13 零用量、失败，不惩罚账号；401/429/5xx 保持旧分类。 |
| WS/合约边界 | 16 MiB 等于/超过仍按未压缩 WS frame；预检和早期1009的合法 HTTP 单轮回退可压缩；生命周期后1009/EOF不重放；原生WS、续接拒绝、第三方responses、compact、Images、辅助接口均不压缩。 |
| 并发/内存上限 | 30 MiB 重复文本、伪随机及合成 base64；4 个 permit 与第5个请求竞争（用各略大于 8 MiB 的正文，避免先触发 48 MiB 入站预算）、两 worker 队列取消、编码错误及预算释放；输出背压仅保留有界块，明文降级在发送前决定。对照关闭压缩的 RSS 峰值，区分 JSON/序列化既有峰值和新增工作区，新增估算/容量超出则阻止交付。 |
| 协议与隐私 | 假上游流式解压到有界比较器，截断/额外帧/错误尾部被检出；未知字段及键顺序完全相同；无重复编码头、无错误 Content-Length；日志仅固定桶，限频/中断值正确，无正文或任意标识。 |
