# 首页运营概览验收

记录首页布局、诊断入口和资源观测的验收。

- [x] 核对请求卡宽屏、窄屏和空态。Chrome 合成五条在途请求验证首行四张和两张，以及新快照移除已结束卡片。
- [x] 核对额度、失败筛选和资源卡合成快照。
- [x] 本机网关实时模式通过 Chrome 连续请求验收。
- [x] 移除请求关注后验证在途卡片随结束事件移除。旧实时字段仍为空数组，前端可接收旧版含历史结果的快照。
- [x] 验证推送更新 CPU、内存和数据盘，断线启动轮询，重连后停止轮询。
- [x] Chrome 合成浏览器验收：实时来源失败可重连获取完整快照；断线时在途卡标为待确认、暂停计时，HTTP 快照到达后移除已结束卡。
- [ ] 验证 Linux 主机采样。真实进程验收等待第二次 CPU 样本，并核对 WebSocket 与 HTTP 中的 CPU、主机内存和进程 RSS。
