# 首页运营概览

大屏左栏显示用量、在途请求和今日活跃 Key，右栏显示账号额度和运行资源。正常准入不显示横幅，确认受阻显示原因及处理入口。单对象提醒在对应区展示，协议观察保留诊断入口。请求卡随在途快照更新，结束后移除。删除关注和固定观察，网关仅发送移除在途卡所需的结束信号。实时 v1 保留空的 recentlyFinished 字段供旧管理页面解析。Key 表按已观测 Token 降序，失败率沿用失败数除以准入数及既有诊断跳转。

资源为管理员只读数据，复用存储快照的 HTTP 与实时来源。采样由运行时监督，内存中最多保留最近一小时，不涉及数据库迁移。Linux 使用进程驻留内存、整机可用内存和 CPU 采样区间内非空闲比例。不可读取的平台或字段显示未知。回退后旧前端可忽略新增字段。
