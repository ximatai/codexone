# 完整额度周期趋势

首页额度趋势的历史最多保留 24 小时，多日周期无法看到周期前半段，图表左端也不代表周期开始。用户需要从周期开始到重置的完整时间范围，历史只显示实际记录。

- 为每个额度窗口保存当前周期内的观测历史，覆盖服务端允许的窗口长度；周期变化、重置或余量回升时仍按既有规则重新起段。
- 横轴以实际周期开始和重置为边界，当前时间与预测保留；没有观测的区间留空，不凭空补 100%。参考时段仍只决定预测输入。
- 保留缺口，不把稀疏采样连成完整观测；预测只使用时间覆盖可信的数据。数据量、查询、传输和保留须有上限，并避免当前 16 KiB 记录上限导致早期历史被批量丢弃或覆盖当前额度。
- 既有历史可继续展示；已经被删除的旧样本无法恢复。升级和回退明确说明数据库及旧版本兼容，失败不能损坏当前额度和其他账号记录。

相关规范：[首页额度趋势](../../reference/specs/control-plane.md)。验收包括多日周期、真实采样缺口、容量上限、重置、重启、并发及数据库失败，浏览器验证大屏和窄屏。

容量参考：在 macOS 本地 SQLite 的合成测试中，一个账号两个一年窗口、共 210240 行约占 16.6 MiB 数据库空间；批量重置一个窗口产生约 13.1 MiB WAL。按 64 个账号线性粗估数据约 1.1 GiB，实际大小取决于标识、数值和 SQLite 页布局；备份及迁移需要额外空间。新表采用五分钟桶和窗口最大一年边界，不依赖无限增长的队列。
