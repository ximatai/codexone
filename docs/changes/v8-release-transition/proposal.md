# v8 安装候选与可回退切换

依据 O03/O04/O08/O13/O16，更新包含快照维护、多版本主密钥与存储压力能力的 Linux amd64 候选。保留精确源码/镜像/二进制校验与依赖许可证，实际 release 验证维护能力；不把旧 v6 候选重标为 v8。

安装验证沿用受控 Compose 入口和同一私有本地卷：空安装、旧 schema 显式备份迁移、升级后 Key/账本保留；以真实前一 v8 二进制演练兼容回退再升级，以旧 v6 二进制证明拒绝 v8 且不修改数据。备份恢复与二进制替换分别处理，拒绝降 schema 或丢掉新账本。

合成旧服务与新服务保持独立数据/凭证，列出端点/provider/Key/账号/用量/历史归属的映射及换发清单。演练停止旧入口接单、有界收敛、路由切至新服务，记录新增执行与 unknown；切回时停止新入口、保留新增责任并向旧侧保守核对基线，不重放或回滚余额。仅证明合成转换方案，Desktop、真实订阅与 M5 不纳入完成声明。

阶段由主 Agent 实现和定向验收，提交后集中 subagent review，修复后集中跨平台与实际镜像/浏览器验证；未改变的核心/前端全集沿用已通过结果。容量演练另为下一闭环，不做真实导入/调用/部署或推送。
