# 首页 Key 今日估算费用

在「今日 Key 请求汇总」展示各行业务日内账本已记录的估算费用。复用已有的费用金额，以可选字段标记金额是否只覆盖部分费用。沿用用量页的美元显示格式，缺失显示「—」，下界显示「≥」。沿用现有 Key 范围、顺序和窄屏布局。

HTTP 与实时快照共用摘要，旧页面可忽略新增字段。旧服务缺少金额时显示「—」，有金额但缺少完整性标记时按下界展示。无需迁移，回退只需切换程序和配套网页。

验收覆盖已知零、无记录、部分费用、业务日边界及宽窄屏展示。费率计算和历史账本不在变更范围内。
