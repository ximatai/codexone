# 编辑已启用文本模型费率

管理员可在模型目录查看和编辑已启用文本模型的输入和输出费率，单位为美元／百万 Token，保存精度为整数微美元。复用目录 revision、费率校验和持久化。保存后新请求使用新费率，已准入请求继续使用准入时的费率，历史账本保留原值。模型持续可用，网关无需重启。

验收涵盖管理员写入、金额上下界和精度、目录冲突、重启恢复与管理页面流程。此次范围限于已启用文本模型的标准输入和输出费率。

同步管理面的模型目录规范和用量规范。沿用现有目录数据结构，无需迁移。回退到上一版本仍可读取并使用已保存费率。
