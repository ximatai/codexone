# CodexLB 接入取舍只读核对

依据 P11、C10/C11、I15、U10 与首版现服务替代目标，对用户指定旧项目的明确源码版本，核对恢复、认证额度、图片、模型目录及失败策略。交付版本限定的证据矩阵和后续顺序，纠正此前证据解释过窄之处。

本阶段不改变运行行为、安全/用量/schema 或恢复语义，不修改旧项目、不访问其数据/秘密、不联网刷新仓库、不调用真实订阅、不修改Desktop配置。旧源码只能证明存在实现路径，不能代替客户端/真实提供者或线上版本验收。冻结候选继续保持原标识。

验收：主Agent亲自逐项读取双方源码及相关测试，分离完整事件重放、上下文重建与再次执行；结论引用提交、相对源码位置与限制。归纳后提交并集中只读review；只运行文档/架构/差异与隐私检查，不重复未改代码的全量验证。需要新行为时另建提案和定向试验。
