# 首页汇总与容量展示

首页大数值与容量说明难以扫描，最近请求明细重复用量页。改为按中文量级展示指标（保留精确值提示），容量以进度条区分参考阈值与阻断上限，今日各托管 Key 的成功、失败、取消和其他结果汇总代替最近请求；逐笔诊断仍在用量页。

沿用 U12/U14 与管理面只读预算：扩展 `/api/usage/keys`，增加 UTC 当日 succeeded/cancelled 终态计数。pending 是结算状态，可能与成功/失败重叠，不能用于推算结果；执行中为 intent 数，结果未明为 admitted 减去三个已知终态与执行中数。包含无流量 Key；最多 256 个，超限报错而非截断。无 schema、授权、计费或恢复变更，旧客户端忽略新增字段。

验收：大整数格式与精确值、零/缺失/超阈容量、Key 结果互斥统计、UTC 边界、取消与未明结果；首页不再请求逐笔明细；自动刷新、失败重试与窄屏保持可用。

## 大屏布局与表达优化

按 1920×1680 复核：拓宽侧栏、压缩普通提醒与无进行中请求时的空状态、合并管理连接与生成就绪状态，将账号并发放回账号卡片，移除重复待核对数量。标题改为资源使用，解释账号不可用原因及失败类别占比。Key 摘要补充 inFlight，执行中与结果未明分开计数，沿用只读预算，无 schema 变化。保留公开的未登录连接检查入口。

## 进行中请求列

按用户复核，将 Key、模型/模式、推理强度、订阅账号、运行时长、首事件拆为独立列。只读进行中接口投影已持久记录的 reasoningEffort 与 requestMetadataRecorded，不新增上游调用、采集或 schema。显式值原样展示；已记录但未指定显示未指定，历史缺失显示未记录；不猜测模型实际生效强度。仍只读 intent，最多200条，沿用取消和扫描预算。

## 首页账号详情就地打开

首页账号名、进行中账号链接及带明确账号 ID 的提醒使用首页 account 查询参数就地打开已有账号详情抽屉，保持首页导航与滚动上下文；订阅账号模块的 target 链接保持原行为。复用账号详情及授权操作，不复制授权/事务逻辑。关闭仅移除 account 参数；浏览器返回与刷新按 URL 恢复。缺失账号、首次读取失败须在抽屉中明确反馈；会话失效清理参数，账号变更刷新首页观测。无后端接口或 schema 变更。

## 账号详情信息重排

账号抽屉默认概览展示健康与额度，自动化和设置分为独立页签；固定标题/关闭入口，面板内容独立滚动。自动化配置按需展开读取，分区保存；同一账号切换页签保留已加载面板及编辑状态，切换账号重新初始化。技术版本与UTC时间置于详细信息。沿用原有授权、确认、CSRF、取消、计量与保存事务，不新增真实调用或默认启用自动化。

## 精简辅助文案

统一去除首页与账号抽屉的重复说明、图例、正常状态布尔说明及重复入口，优先用分组/表头表达含义。必要口径保留在上下文提示、无障碍说明或明确确认步骤；额度消费、授权替换、未知结果及失败提示保留。结果汇总改为表头定义的数值列，不重复每行标签。纯展示调整，不改变默认设置、确认、授权、计费、恢复与独立保存语义。

## 提前量单位切换

按用户确认，单输入合并分钟/小时选择，整小时优先小时，否则分钟。以分钟保存实际时长，切换单位不修改时长；小时支持小数，保存仍要求整数分钟及原重试预算。非整小时换算展示至8位小数，浮点容差只消除换算误差，不静默取整用户输入。API、调度及schema不变，无迁移；回退仅影响输入展示。验收19小时/1140分钟往返、727分钟往返、空值和小数分钟拒绝、保存协议与宽窄屏。
