## 实际验证（2026-11-06）

macOS arm64、Swift 6.4.2 上通过后端构建、严格格式及 507 项 Swift 测试。九项本地 socket 检查覆盖 JSON 顺序、原生图片、原生 WS、上游事件、辅助接口、协议拒绝、可选推理、WS 大请求与请求参数。测试使用合成上游，验证了 HTTP 模型头与过滤、HTTP/SSE/原生 WS 和桥接错误等待提示、上游升级拒绝、未知字段、图片事件和不重放。旧推理测试原先要求删除全部 null，已更新并重跑，分别验证已知字段省略和未知字段保留。

[Linux Verify](https://github.com/ximatai/codexone/actions/runs/42147986756) 已通过。当前候选的非流式 PNG 对照和断开证据见[原生生成验收](../native-image-json/tasks.md)。真实 Codex CLI 已验证原生 PNG 生成并保存。

v0.26.11-rc.2 在线上使用 Codex CLI 0.165.0、同一个订阅账号与同一张合成参考图，对照直连和经网关各一轮。对话模型为 gpt-6.1-sol，原生图片模型为 gpt-image-2。两边都得到 PNG；网关侧确认只派发一次原生 edits，上游 200，账本单条成功且用量完整。直连核对客户端结果，未采集上游原始数据包。本轮为 CLI 验收。

本机另复用现有中断用例和协议、压缩续接、原生 Images 的真实 socket 检查，均通过。只为输出项中断补充一条合成事件断言。
