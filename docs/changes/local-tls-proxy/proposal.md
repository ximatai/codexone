# 本地 TLS 反代与 HTTPS 管理闭环

依据 O06/O10/O11、P11 与管理 session 契约，验证真实 TLS 客户端 → Nginx → loopback 网关 → 无凭证合成上游，补齐安装候选之后的独立 M6 接入闭环。主 Agent 实现和定向测试，出口提交后集中 review。仅隔离的本地进程/容器，不更改用户反代、系统证书信任或旧服务，不进行真实账号调用、推送与部署。

交付可复用数据/管理 Nginx snippets 和明确的 TLS server 示例；保留域与端口、限制和超时，关闭生成代理自动重试、响应缓冲及敏感请求日志。测试实际加载交付 snippets，而非另写一套通过的配置。

验收：临时 CA/叶证书、客户端验证链及主机名（不信任/错误主机拒绝）、HTTP JSON/逐事件 SSE、WSS Upgrade 与后续 turn、两数据前缀、下游取消与读超时不重放且保留 unknown、大小限制及管理面隔离；浏览器经真实 HTTPS 登录/CSRF/Key/刷新/登出，安全 cookie、错误 Host/Origin 与伪造 forwarded 头不能绕过授权。证书/密钥仅存在私有临时目录，日志/截图无秘密。短超时仅为故障注入，交付默认超时不变。

Desktop、真实订阅、M5 读取/缓存、目标宿主容量、数据/密钥维护和旧服务替代均不在本闭环内。浏览器仅对本次叶证书作临时 SPKI pin，不修改全局信任；独立 TLS socket 验证 CA 链与主机名，不能把 pin 例外声明为公共证书发行验收。
