# 首页订阅额度趋势任务

记录采样、预测和浏览器验收范围。

- [x] 持久化现有上游读数并提供按需管理读取。
- [x] 展开趋势，区分历史、预测、粗估和数据不足。
- [x] 验证存储、模型与合成浏览器流程。

macOS 定向 Swift 测试覆盖重启、主次窗口隔离、读失败和重置边界，以及真实管理 HTTP 路由的认证与 no-store。Chrome 合成用例覆盖 1440px 和 390px 的按需读取、键盘展开、时段切换、收起和过期暂停。前端单测覆盖缺口、粗估与真实零值。复盘追加了额度记录容量边界、缺口内下降降级，以及切换时段时图表位置与高度不变的回归检查。
