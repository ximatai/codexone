# 首页订阅额度趋势

复用订阅额度观察任务，记录各账号 Codex 主、次窗口最近 24 小时的上游剩余比例。首页点击进度条展开趋势，显示参考时段、实际读数、预测和重置位置。采样与预测不参与准入、重置卡或费用计算，也不增加上游请求。

历史随现有额度记录持久化，使用可选字段与原行大小上限，无 schema 迁移。旧版本可读取额度记录，更新时可能清空趋势历史。只保存时间和归一化额度比例等窗口元数据。管理员按需读取单个账号历史。窗口重置、额度回升或窗口定义改变时重新采样。

以[管理面规范](../../reference/specs/control-plane.md)为验收依据，验证采样边界、失败保留、重启以及桌面和窄屏展开流程。
