# 上游额度重置时间与账号冷却

上游 429 有时只返回 `resets_at`。网关已向客户端转发该字段，但内部会按缺省 30 秒冷却，之后可能继续派发到同一个额度仍未重置的账号。

对已归类为上游限流的错误，在现有数字 Retry-After 和相对秒数均不可用时，用未来的整数 epoch 秒 `resets_at` 与观察失败时的时钟求差。继续使用 3600 秒上限；过期、非整数、超出整数表示范围或格式无效时沿用缺省 30 秒。只应用到既有账号健康记录，不扩大冷却作用域、修改客户端错误或改变重放与准入规则。关联 [P10/P27](../../reference/specs/protocol.md) 与 [账号健康规范](../../reference/specs/identity.md)。

无数据库或配置迁移。回退后已写入的截止时间沿用既有字段，之后的新错误按旧行为处理。
