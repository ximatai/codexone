# 管理会话时长与登录用户名

日期：2026-10-31。修改[管理面](../../specs/control-plane.md) A10 管理员会话契约。

## 问题

管理会话绝对寿命 30 分钟且不续期，用户频繁被登出。登录页只有密码框，浏览器不会触发“保存用户名和密码”。

## 风险取舍

管理员为单人自用（见共识决策治理姿态）；管理域经 TLS 公开。延长寿命的风险是 Cookie 被盗后可用更久，由 HttpOnly/Secure/SameSite=Strict、来源校验与绝对上限约束。

## 行为

- 会话改为滑动空闲过期 24 小时：每次已认证的管理请求刷新最后活动时间；绝对寿命 7 天（命名常量）。Cookie `Max-Age` 设为绝对剩余寿命并在续期时一并刷新（不超过绝对截止）。
- 会话仍仅存内存，重启失效；数量上限、CSRF、撤销、旧 Cookie 不阻塞重新登录等契约不变。
- `POST /api/session` 请求体增加必填 `username`，必须等于固定值 `admin`（命名常量）；用户名或 secret 任一错误返回同一认证失败，不区分原因，限速与计数不变。headless 管理凭证路径不受影响。基线没有独立的登录失败次数限速，本变更保持现有连接数、并发数与期限限制，不新增限速策略。
- 登录页增加“用户名”输入框（默认 `admin`，`autocomplete="username"`，`name="username"`），密码框 `autocomplete="current-password"`，表单为标准 form 提交语义，使浏览器可保存凭证；不在本地存储中保存任何凭证。

## 验收

- 空闲 24 小时边界过期、活动续期、7 天绝对截止、续期不超过绝对截止；重启失效；退出撤销。
- 用户名缺失/错误与密码错误同一响应；限速不变；未知字段拒绝。
- 前端：字段与 autocomplete 属性、默认值、错误提示统一、浏览器可识别的表单结构（Playwright 检查）。
- 规范同步；`verify.sh --backend`、`verify.sh --web --chrome`；主 Agent Linux verification。
