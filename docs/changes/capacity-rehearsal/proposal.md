# 有界混合容量演练

依据 O09/O12/O14，对已验 v8 优化运行镜像做受限容器合成演练，先测量再给操作包络，不以容器限额冒充完整目标宿主。记录 Linux VM 的 CPU/内存/swap/负载和共存容器数量、amd64/宿主架构与可能的仿真。当前约 2.9 GiB VM 不等于 1.6 GiB 参考宿主；M5 缓存、真实订阅/Desktop、实际旧服务负载继续留缺口。

网关使用实际运行镜像、1 CPU/768 MiB/128 PID、非 root/只读及 Linux 本地命名卷。合成提供者/压测器在独立受限 cgroup，仅共享隔离的 loopback namespace，不挂 Docker socket、不访问外网或旧服务。命令、配置、日志和结果不得记录秘密、正文、图片或私人路径；所有临时资源都有本次随机归属与结束清理。

工作负载包括多 Key HTTP JSON/SSE、下游 WS、warmup/compact、约 3 MiB 合成有效 PNG 的生成/编辑、有限断流/unknown；分别覆盖 HTTP 和原生 WS 上游。独立超载批次超出连接上限，检查有界拒绝、无重放和收尾。持续阶段固定最大4个在途、明确限速和时长，不用无限生产队列制造压测器假负载；先短程定位，再运行600秒持续样本。低磁盘故障沿用已通过的独立真实 ENOSPC 证据，不在本阶段填宿主磁盘。

记录每种操作吞吐/状态/延迟、实际提供者调用和账本真相、RSS/cgroup峰值/FD/线程、writer队列/等待、DB/WAL与回稳。Linux线程数不是Swift async task tracing；存储观测峰值RSS不是当前RSS，另从进程和cgroup读当前值。退出前确认intent收敛、保留unknown、队列归零、WAL checkpoint和资源稳定，不能退款或删除责任以制造恢复。没有实测全部峰值/长压或目标环境时，不标O14完成。

主 Agent 亲自实现/定向测试，业务样本完成并提交后集中review，修复先跑相关回归，阶段出口跨平台检查；不重复未改业务代码的175项或前端全集。
