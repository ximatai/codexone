# 管理台走查修复

日期：2026-10-31。按合成走查的 O01–O03、A01–A03、K01–K09、U02–U03、L01–L02 共 19 项修复，延续 [管理台基础层](../admin-ui-foundation/proposal.md) 的「C 结构 + A 克制」、石墨蓝主色与状态色语义。界面契约见 [control-plane](../../specs/control-plane.md)。不改后端 API、schema、准入与会话安全边界。

- 未成功读取时仅显示失败/重试，数量不可用；成功空列表才显示空态。保留旧快照时标记读取时刻和失败。
- 提醒携带对象 ID；账号直接打开详情，Key 定位并高亮，隐藏/不存在时明确提示。
- Key「可用状态」：可用=启用且未到期；即将到期=可用且七天内到期；已到期不论开关；已禁用=未到期且关闭。列表同时显示开关与有效期，不代表模型/限额等全部准入条件。
- 到期按真实 UTC 时刻显示，编辑日期未变时保留原秒值；主动改日期明确预览 UTC 零点的新值。创建/编辑可保存过去时间，但统一警告「保存后立即拒绝新请求」。阈值按六位小数精度显示。
- 非敏感筛选和页码进入 query；用量游标、固定查询窗口及滚动位置只在管理会话内存保留，登出/会话更换清除。不缓存结果正文或秘密。翻页回请求列表顶部，返回恢复筛选/页码/位置。
- 共用表头在页面滚动中吸顶，避开顶栏；Key 客户端每页 50 条；提醒默认五条并展示风险总数与展开入口。大屏与窄屏无横向溢出，不增加表格纵向滚动容器。

验收：每个 P1 有回归测试，覆盖 503/429、成功空态、长名称、原到期秒值保存、轮换目标、提醒定位与列表返回/翻页；完整前端入口、文档检查与合成浏览器走查。只在当前 worktree 开发，无真实服务/订阅调用、Docker/Linux、推送或 PR；STATUS 不变。
