# 模型和推理档位拒绝日志

对通过 Key 认证、已完成解析但被模型或推理档位校验拒绝的 Responses 请求，在服务端既有协议告警中附上请求侧模型和推理档位。HTTP、压缩和原生 WebSocket 共用选型校验。模型原值限可信配置中的机器标识或符合常见 OpenAI 模型系列格式的标识。档位原值仅限已知枚举，区分未提交和无效值，单独标记旧顶层字段。日志继续使用现有请求 ID 和限额。

公开错误、用量诊断和准入规则沿用现有契约。不记录原始正文、凭证或其他字段。无数据库和配置迁移，回退后不再生成新增日志字段。
