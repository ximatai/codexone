# 首页输出速率排除生图请求

首页请求输出速率使用宿主对话的输出 Token 除以完整耗时。独立 Images 路由已排除；Responses 生图工具执行期间的耗时也包含在宿主请求中，不能代表普通文本生成速率。

按可信结算证据排除实际生成图片的请求，仅声明生图工具但没有执行的对话仍参与。首次完整结算不记录生图样本；迟到的更高版本证据确认生图时撤销已记录样本。重启恢复时在样本数量截断前过滤历史生图证据。无法完整结算的请求沿用不计样本的规则，不猜测图片结果。其他用量、费用和限制不变。迟到修订补位时，启动时钟秒及之前（或启动时已有未来时间戳范围内）且已从内存桶淘汰的样本无法可靠证明是否本进程结算，近 60 秒保守不计；历史小时和日趋势照常补位。

不修改 schema 或原始用量记录；旧版本回退会恢复旧速率口径。覆盖实时、证据修订、重启和历史容量边界，核对真实 Responses 图片工具路径。相关规范：[首页实时速率](../../reference/specs/control-plane.md)、[用量](../../reference/specs/usage.md)。
