# 独立旁路试运行与验证摘要导入

依据I01/I07/I12、A10、O13，用户授权独立服务器旁路部署、复用旧Key字符串，首轮仅选一枚Key与合成上游。旧服务保持原样；新库、管理凭证、进程与账本独立，不复制登录凭证或响应归属，不开启真实订阅。

新增离线 `--import-keys ABSOLUTE_MANIFEST`，只向无Key/审计/执行/账号且非恢复态的新库导入。0600普通文件、1MiB、最多256条、采集不超过5分钟且未来偏差不超过60秒、严格字段/唯一ID/摘要/主体/策略；整批验证、同一事务持实例锁、全部禁用、每条审计，不接受明文，不覆盖/重复导入。与管理员摘要相同拒绝。仅导入源当前启用、无过期时间、且权限可等价或更保守表达的条目；停用/带过期时间/未知策略由源转换器隔离，不放入可启用Key表，不能冒充完整兼容。转换器输出私有隔离清单，绝不静默放宽。旧、新撤销和用量不自动同步，源快照不是持续授权。

服务器首轮读取旧库一致性只读快照，仅把验证摘要和经审阅的策略写入新私有目录；不复制原表、不读账号凭证。导入后只用既有CAS管理API启用用户指定Key，其余禁用；独立小额度不称继承余额。新服务只连自有合成上游。入口优先loopback+SSH隧道，不改旧反代/DNS/防火墙；需要其他客户端入口再明确。

验收：原始旧格式合成Key跨HTTP/WS认证与限额、其他Key禁用、重复/冲突/部分失败原子性、实例锁、文件权限/链接/容量、坏摘要/源状态/管理员冲突、元数据/日志无验证材料；旧服务状态保持，远程合成健康/认证/未启用Key拒绝及无真实凭证/真实上游配置。主Agent实现/定向验证后提交、集中review修复，出口完整后端与Linux优化程序验证，再部署独立测试候选。真实客户端操作由用户选择客户端后另验，不标Desktop或真实订阅通过。
