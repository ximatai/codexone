# 独立旁路试运行与验证摘要导入

依据I01/I07/I12、A10、O13，用户授权独立服务器旁路部署、复用旧Key字符串，首轮仅选一枚Key与合成上游。旧服务保持原样；新库、管理凭证、进程与账本独立，不复制登录凭证或响应归属，不开启真实订阅。

新增离线 `--import-keys ABSOLUTE_MANIFEST`，只向无Key/审计/执行/账号且非恢复态的新库导入。0600普通文件、1MiB、最多256条、采集不超过5分钟且未来偏差不超过60秒、严格字段/唯一ID/摘要/主体/策略；整批验证、同一事务持实例锁、全部禁用、每条审计，不接受明文，不覆盖/重复导入。与管理员摘要相同拒绝。仅导入源当前启用、无过期时间、且权限可等价或更保守表达的条目；停用/带过期时间/未知策略由源转换器隔离，不放入可启用Key表，不能冒充完整兼容。转换器输出私有隔离清单，绝不静默放宽。旧、新撤销和用量不自动同步，源快照不是持续授权。

服务器首轮读取旧库一致性只读快照，仅把验证摘要和经审阅的策略写入新私有目录；不复制原表、不读账号凭证。导入后只用既有CAS管理API启用用户指定Key，其余禁用；独立小额度不称继承余额。新服务只连自有合成上游。首轮入口使用loopback+SSH隧道；按后续明确授权增加独立公网HTTPS数据域，沿用既有TLS数据面策略与独立ACME webroot/证书续期，不改旧服务路由，不公开管理入口。客户端仅改服务地址，认证摘要与合成上游保持不变。

验收：原始旧格式合成Key跨HTTP/WS认证与限额、其他Key禁用、重复/冲突/部分失败原子性、实例锁、文件权限/链接/容量、坏摘要/源状态/管理员冲突、元数据/日志无验证材料；旧服务状态保持，远程合成健康/认证/未启用Key拒绝及无真实凭证/真实上游配置。主Agent实现/定向验证后提交、集中review修复，出口完整后端与Linux优化程序验证，再部署独立测试候选。真实客户端操作由用户选择客户端后另验，不标Desktop或真实订阅通过。

公网入口验收：可信公共证书与主机名、HTTP跳转、JSON/SSE/WSS、缺失/错误/撤销Key拒绝、管理/健康路径不公开、旧服务配置与容器保持；公网测试使用新建诊断Key并最终撤销，不读取旧Key明文。公网可达不代表真实客户端或订阅兼容通过。

客户端合成联通闭环的后续修复：实际客户端报unsupported_reasoning；独立合成对照复现effort/summary显式null被误拒。只读参考CodexLB的ResponsesReasoning可空字段与model_dump_for_forwarding(exclude_none=True)，仅将这两个已知可选成员的null按未指定处理，转发前移除；保留显式非null值、未知字段/错误类型/大小拒绝及tools缺省/显式空数组的区别，不吸纳extra=allow或别名兜底。需实际HTTP JSON/SSE、桥接/native WS验证最终上游无null、失败无dispatch，真实客户端继续单独验收。

实测候选部署因135MiB镜像与受限代理带宽耗时超预期。运行候选剥离DWARF调试段（保留可执行代码与符号表），验证剥离后的同一程序；私有部署复用已校验的旧归档相同内容段并重建新归档，要求本机重建及目标最终SHA与完整导出的候选逐字节一致，不修改旧归档，不跳过正常镜像/程序校验。

公网更新后用户再次请求仍报unsupported_reasoning，所选Key无attempt，故nullable reasoning不是唯一原因。后续增加固定枚举的拒绝细分（对象/未知成员/effort类型/summary类型或取值），仅脱敏日志包含枚举，不包含字段名、参数原值或正文，公开错误码/准入语义不变。同时依据明确可空的旧源码契约，规范化text.verbosity/format、tool_choice/parallel_tool_calls的null；只删除这些已知位置，错误类型/未知字段仍拒绝。验收覆盖实际四传输最终上游文档、拒绝不派发和诊断隐私/上限；更新候选后再次核对用户请求，不猜测或放宽未知reasoning成员。
