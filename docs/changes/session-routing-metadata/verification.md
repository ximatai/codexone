# 会话路由与元数据验证

记录本次修复的合成协议验收与平台边界。

[跨项目复盘](review.md)发现的续接来源与 WS 载体缺口已按透明优先契约修复；下方新增验收为最终实现证据，旧通过记录不替代新场景。

## 透明优先修复的最终验收

2026-11-02，macOS arm64、Apple Swift 6.4，全部为合成服务：

- `CODEXONE_BUILD_JOBS=4 ./scripts/verify.sh --backend` 通过：408 项 Swift 测试（66 + 77 + 7 + 258）、34 个后端验收脚本。严格格式、生命周期、文档、架构检查包含在内。
- 最后将未派发的未知来源与畸形状态分类为 accountUnavailable/invalidRequest 后，定向 6 项复测通过；没有改变准入、转发或结算行为。
- 实际 HTTP/WS 证明：已知来源固定账号，来源禁用与未知 token 均拒绝且无额外 intent；HTTP→WS 显式状态进入消息 metadata、握手不携带本轮状态。
- 101 无头、仅 metadata 事件返回状态的 JSON/SSE 桥接通过；原生首消息兼容握手、后续不自动注入，跨固定连接 owner 的消息被拒绝。
- Key 隔离、跨账号 token 冲突墓碑、TTL、容量、父子线程独立位置与 process seed、重复/冲突载体有回归；未知状态不会变成对象授权或 draining 资格。
- 固定来源账号在另有健康候选时仍正常刷新；凭证刷新期间新增/到期的冷却在实际选择点读取；Key 撤销/到期优先于冷却拒绝。
- 429 保留账号级保护，辅助 5xx 只隔离端点；辅助切换不影响主 token 来源。真实控制期限、断连、代理/TLS、迁移切回与隐私脚本通过。
- 独立 subagent 只读复审确认刷新候选修复，未发现新的阻断 P1/P2；复审未自行跑测试，测试结果以上述执行记录为准。

无数据库或 Key 格式迁移。token 来源为有界内存记录，重启/TTL/淘汰后拒绝未知来源；不提供透明恢复。未调用真实订阅、未执行该分支 Linux CI、未发布部署。普通事件与请求内容按既有契约透传，不推断辅助 HTTP body 的身份语义；不保证提供者缓存命中率。

## 复测与异常记录

- 代码噪音收敛后，定向 32 项 Swift 测试通过，覆盖软亲和、续接来源、跨传输元数据、凭证刷新、辅助冷却和 Key 失效；严格格式、文档、架构和差异空白检查通过。此次仅简化重复计算、控制流与私有参数，没有重跑全量后端脚本。
