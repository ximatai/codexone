# 变更约定

行为、协议、安全、schema 或恢复语义变化时，建立 `<slug>/proposal.md` 与 `tasks.md`，说明目标、排除项、规范影响、验收及数据/回退影响。任务用复选框，实际验证附带日期和范围。

活动任务保留在下列目录，路线图在根 STATUS 概览。变更完成后把目标与达成的结论同步到规范/架构，过程文档可回收，由 Git 保存历史；不另建长期堆积的讨论归档。纯文案整理无需为了流程再建一份提案。
