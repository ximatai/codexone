# 恢复关联实验 · 2026-10-23

主Agent实现有界临时relay与合成提供者，实际CLI 0.163.0连接真实网关。网关先收到完整可信终态并settled，relay仅向客户端交付created或文本delta前缀后截断；客户端重试时按明确实验步骤返回同一完整事件，不增加网关/上游执行。该内存夹具不是生产缓存或请求识别算法。

macOS首轮夹具未报告cached token，用量partial导致原执行unknown，断言失败；补齐合成完整用量后通过，没有改结算规则。两种截断均观察到请求正文/选取的头完全相同；主动resume同线程发相同prompt时，input/client_metadata与turn metadata改变，而session/thread保持。各重放只呈现一个最终文本；主动新turn实际新增第二次上游调用与settled。拒绝权限/epoch及不同凭证不读缓存/不新增上游调用，仅证明夹具的实验守卫，不是产品授权能力。

结论：该版本CLI HTTP文本路径具备有条件的透明POST读取可行性；未找到消费序号，不承诺部分位置续读。真实工具副作用、图片、WS/不同客户端、崩溃窗口、生产逻辑操作识别与权限/代际重查均未实现/未验，不能仅用指纹或次数上线，M5仍未完成。报告只留字段比较/次数，没有正文/头值/路径。Linux及集中review在出口核对。
