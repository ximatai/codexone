# 额外使用积分余额走势

账号详情概览中的订阅额度面板按需展开积分余额走势，支持近 24 小时与近 7 天。复用自动及手动额度观测，保存账户级余额的十进制读数，每五分钟保留最近一次有效数值。近一天保留五分钟分辨率，更早的连续读数按小时展示。保持持平、增长和缺采样断点。图表和余额均显示整数。

历史采用独立的有界 SQLite 表，随完整快照保存。schema v15 从符合现有自动升级条件的 v14 迁移；旧版本回退需要升级前备份。历史从升级后采样开始。积分记录用于展示余额，不参与计费或选路。

规范见[管理面](../../reference/specs/control-plane.md)、[用量](../../reference/specs/usage.md)和[运维](../../reference/specs/operations.md)。
