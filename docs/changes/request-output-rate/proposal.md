# 请求输出速率

首页改用每笔请求的主模型输出 Token 除以网关记录的端到端请求耗时，近期与日趋势均取中位数。原先把整笔用量压入结算秒的统计会高估单笔输出速度。等待首事件计入本笔耗时，空闲间隔不产生样本；零输出、缺少正耗时及独立图片与 SVG 作者用量不计入。

仅在首次完整证据成功提交后采样。近期取近 60 秒结算样本，日趋势按结算业务日归档。每个业务日保留最近 4096 笔，最多 7 天；该版本当时只在进程内保留样本，持久化边界见[后续变更](../persist-output-rate-history/proposal.md)。为避免旧前端误读新口径，使用独立的可选 WebSocket 字段；前后端版本不匹配时读数留空。无 schema 或数据面改动，回退只影响指标展示。
