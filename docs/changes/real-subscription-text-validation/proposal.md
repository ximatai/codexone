# 受控真实订阅文本验证

用户已授权按建议调用真实订阅，并明确允许使用旧服务或本机的既有账号身份。先验证短文本生成与第二轮续接，不以合成结果替代真实提供者结果；不扩展为正式切换、发布或旧服务迁移。

## 范围与取舍

- 只读核对旧服务状态及账号元数据，选择仍有效的访问凭证快照，不拷贝/调用refresh token，不改变旧服务配置、账号、刷新或运行进程。敏感内容仅在SSH/私有进程内传递，不输出到聊天、仓库或公开日志；临时文件0700目录/0600文件，结束只清除访问快照及管理凭证，独立账本保留用于核对，不能随临时目录清理。
- 本轮先用现有M2静态单身份能力在本机临时loopback实例连接固定官方订阅目标，不创建已验证账号、不绕过M3身份验证、不导入个人登录目录。该方式只证明静态访问凭证的数据链路；账号池、初次登录/刷新及服务器出网另验。
- 已观察到测试服务器直连生成上游TLS失败，本机TLS校验通过。原公开合成测试服务保持，不能将本机成功写成服务器真实订阅可用；先完成无副作用网络核对。
- 单一模型、独立管理凭证与托管测试Key，最多4次准入、在途1、未决1；计划仅两次短文本，明确输出上限128 token，不读取用户文件、不执行工具。首个错误/未知即停止，不安排自动重试或重放，不盲目扩大权限/参数。真实用量与缺失证据分别记录，不按未校准价格声称实际费用。
- 第一轮确认真实终态/用量与账本，第二轮用已授权上下文确认续接；只输出安全状态、用量与是否符合约定测试结果，不保存原提供者错误或真实账号标识。未验证项不标完成，后续实际Desktop需独立有界验证。

依据P08/P11/P15、I06/I15及U01/U02；官方认证说明见[Authentication](https://learn.chatgpt.com/docs/auth)，其支持订阅登录不代证本项目内部协议或当前账号能力。

## 预检及首轮后的出口

旧服务明确配置HTTP代理。通过相同已授权代理的CONNECT/TLS检查，两固定官方目标均通过；已有账号的只读额度GET返回200、allowed且未达限额，未刷新凭证。新网关数据、认证、额度HTTP客户端及原生WS均未接入该配置，因此先前直连失败不能归为服务器或账号不可用。

首轮本机隔离网关返回502/upstream_rejected，未获取可信用量，按执行未知记录并停止；不能将额度GET成功当生成通过。只读参考发现旧服务会移除max_output_tokens等订阅不支持参数，而本轮探针携带该字段，构成待证实的请求契约风险；缺少原始上游状态/固定拒绝分类，尚不能确定其为本次唯一原因。后续不静默删除输出上限或把未知当零。

继续真实生成前，先补齐显式可信Clash出网覆盖HTTP/WS/认证/额度、固定无正文失败分类及探针持久账本；合成覆盖代理失败/超时/关闭/不泄漏凭证、参数不能承诺而被忽略的边界，再恢复小范围验证。原合成测试入口及旧服务保持，账号池/刷新及真实Desktop另验。本次首轮探针错误清理了隔离账本，只有脱敏调用记录而缺原始SQLite，明确记录该限制，不伪称未知责任已完整保存或完成恢复验收。
