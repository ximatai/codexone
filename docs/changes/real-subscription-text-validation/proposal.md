# 受控真实订阅文本验证

用户已授权按建议调用真实订阅，并明确允许使用旧服务或本机的既有账号身份。先验证短文本生成与第二轮续接，不以合成结果替代真实提供者结果；不扩展为正式切换、发布或旧服务迁移。

## 范围与取舍

- 只读核对旧服务状态及账号元数据，选择仍有效的访问凭证快照，不拷贝/调用refresh token，不改变旧服务配置、账号、刷新或运行进程。敏感内容仅在SSH/私有进程内传递，不输出到聊天、仓库或公开日志；临时文件0700目录/0600文件，结束只清除访问快照及管理凭证，独立账本保留用于核对，不能随临时目录清理。
- 首个探针用现有M2静态单身份能力在本机临时loopback实例连接固定官方订阅目标，不创建已验证账号、不绕过M3身份验证、不导入个人登录目录。该方式只证明静态访问凭证的数据链路；账号池、初次登录/刷新及服务器出网另验。
- 已观察到测试服务器直连生成上游TLS失败，本机TLS校验通过。原公开合成测试服务保持，不能将本机成功写成服务器真实订阅可用；先完成无副作用网络核对。
- 单一模型、独立管理凭证与托管测试Key，累计最多4次准入（包括已发生的未知调用）、在途1；计划仅两次短文本。首个探针设置128 token输出上限，但订阅契约尚未证实支持，后续不能将其当成已兑现的硬上限，不读取用户文件、不执行工具。首个错误/未知即停止，不安排自动重试或重放，不盲目扩大权限/参数。真实用量与缺失证据分别记录，不按未校准价格声称实际费用。
- 第一轮确认真实终态/用量与账本，第二轮用已授权上下文确认续接；只输出安全状态、用量与是否符合约定测试结果，不保存原提供者错误或真实账号标识。未验证项不标完成，后续实际Desktop需独立有界验证。

依据P08/P11/P15、I06/I15及U01/U02；官方认证说明见[Authentication](https://learn.chatgpt.com/docs/auth)，其支持订阅登录不代证本项目内部协议或当前账号能力。

## 预检及首轮后的出口

旧服务明确配置HTTP代理。通过相同已授权代理的CONNECT/TLS检查，两固定官方目标均通过；已有账号的只读额度GET返回200、allowed且未达限额，未刷新凭证。新网关数据、认证、额度HTTP客户端及原生WS均未接入该配置，因此先前直连失败不能归为服务器或账号不可用。

首轮本机隔离网关返回502/upstream_rejected，未获取可信用量，按执行未知记录并停止；不能将额度GET成功当生成通过。只读参考发现旧服务会移除max_output_tokens等订阅不支持参数，而本轮探针携带该字段，构成待证实的请求契约风险；缺少原始上游状态/固定拒绝分类，尚不能确定其为本次唯一原因。后续不静默删除输出上限或把未知当零。

继续真实生成前，先补齐显式可信Clash出网覆盖HTTP/WS/认证/额度、固定无正文失败分类及探针持久账本；合成覆盖代理失败/超时/关闭/不泄漏凭证、参数不能承诺而被忽略的边界，再恢复小范围验证。原合成测试入口及旧服务保持，账号池/刷新及真实Desktop另验。本次首轮探针错误清理了隔离账本，只有脱敏调用记录而缺原始SQLite，明确记录该限制，不伪称未知责任已完整保存或完成恢复验收。

## 显式出网与固定诊断实施

用户要求继续补齐并完成两轮验证。新增可信环境CODEXONE_UPSTREAM_HTTP_PROXY，显式http://host:port（不支持userinfo、非根路径、query或fragment），不自动采纳进程HTTP_PROXY等环境；未设置或空值直连，非空配置无效拒绝启动且不回显值。统一用于生成HTTP、原生WS（HTTP CONNECT后再做目标TLS和WS）、认证及额度客户端；固定提供者authority、TLS主机名/证书校验、无重定向/自动重试、原期限和关闭owner保持。代理不可用不直连回退；CONNECT不得带订阅/下游凭证。私有配置不进入公开仓库，安装环境显式接入，不改Clash或旧服务。

上游非成功响应记录固定错误码与HTTP状态、服务端UUID；公开message可带有效UUID，不含上游正文/任意字段值。已知输出上限拒绝可用固定枚举识别，不记录原错误字符串，不静默剥离约束。合成覆盖HTTP/WS代理路径、拒绝/超时/取消与凭证隔离、错误关联和持久unknown，检查通过后在独立私有实例进行受控真实验证。上一轮无原始账本的未知调用保留单独审计记录，不伪造回填为成功。

## 继续验证的有界方案

在独立服务器loopback实例使用已验证的Linux产物与旧服务现有代理，仅复制有效access快照，不修改原合成入口或旧服务。选择旧服务只读成功元数据确认的同一模型；请求只要求极短固定标记，不带工具或用户文件，单次60秒、并发1，首个失败即停止。后续探针显式不发送未经订阅验证的max_output_tokens，不承诺token硬上限，不改变网关对下游该字段的透传行为；实际usage单独核对，不以短提示或时间限制代替token上限。第二轮回送首轮完整输出上下文验证续接，原始响应只在私有进程内处理。

探针在派发前追加并同步私有调用日志，生成结束/服务退出后核对并保留SQLite、脱敏报告、产物摘要；仅清除访问快照、管理秘密和临时Key材料。上一轮缺原SQLite的unknown保持独立记录，不能用本次成功抵销。本次范围仍为真实HTTP/SSE数据链路，不能标记真实Desktop、原生WSS或M3账号池/刷新验收完成。
