# 默认客户端完整操作闭环

用户已授权实施并完成修复和端到端验证，本地阶段不部署、不调用真实订阅、不修改个人客户端配置；本地出口后另明确授权升级既有独立合成测试服务，供用户自行操作Desktop。部署限于该测试服务，保留原Key/地址/数据与回退材料，不修改旧服务、不开放真实订阅、不推送发布。接续[可靠性审计](../gateway-reliability-audit/proposal.md)的 A01/A04/A09，依据 P03/P06/P09/P11/P13/P15/P16、E01/E03/E04、U03/U11；不提前实施其余流生命周期、健康冷却或恢复缓存方案。

## 行为契约

- 原生接受有界 `input.additional_tools`，只允许 type/role/tools/可选本地id，role只能developer。复用已支持function/custom/单层namespace的校验；所有工具来源共享64个声明（含namespace）上限，重复/歧义身份拒绝。包内不开放内置搜索、MCP、tool_search、图片或其他执行能力，顶层已有图片工具仍按原映射授权。
- 默认客户端自带工具说明实测约14 KiB，原8 KiB限制会拒绝合法请求。各来源工具说明统一上限32 KiB UTF-8，保留整体请求及声明数量限制，超限仍拒绝，不截断说明。
- 聚合已校验声明供工具输出/选择校验，WS增量继承仅按下一条的有限规则；转发保留工具包位置、角色与数组顺序。本地id不是提供者引用，移除而非登记归属。不把包提升到顶层，不合成缺省tools，不静默删除未知输入。工具call_id、previous_response_id、加密上下文归属保持原屏障。
- 原生WS实测预热携带声明，随后通过previous_response_id增量续接而省略声明。同连接同lane仅保留最近成功响应的有界工具身份集合、Lite标记和模型/响应ID；只有模型相同且明确引用该响应、没有任何新声明时继承校验集合。不补写上游工具、不跨连接/lane继承、不从未知引用获取权限；显式空工具/新声明替换，失败关闭连接即回收。授权与引用归属仍每轮独立校验。
- 以已校验请求的Lite声明/明确的有限协议标识生成上游HTTP Lite header及WS每轮metadata，不直接透传任意客户端header。其仅选择协议，不授予工具或账号权限。实际订阅握手仍待单独真实验收。
- 合成试运行fixture终态/compact补齐一致的total_tokens，保留已知输入输出/缓存计量；不在网关对未知用量补零。可复用同一事件构造来验证工具与压缩，但正常连接检查必须直接使用实际fixture Handler，不能换成另一套返回协议。
- 显式受信目录与客户端默认内置目录分别验证；不把合成模型目录切换当成默认路径兼容。未支持的内置搜索等仍显式关闭并披露，不能声称全部默认功能。

## 验收

主Agent实现和定向验证；隔离固定版本实际CLI、全新0700 CODEX_HOME/空工作目录/固定合成Key，所有生成/目录仅loopback，禁遥测，不读取真实登录与历史。覆盖默认模型无显式目录、显式目录、实际试运行fixture文本、工具往返、第二/第三轮、预热及压缩后续接；HTTP直连/桥接/原生WS分别记录实际传输和上游次数、client exit/turn.completed、完整与失败/拒绝账本，包含跨主体引用/未知或超量声明拒绝不派发。未独立完成的Desktop UI、真实订阅、M5/O14保留。

将实际客户端合成检查作为显式候选出口命令，缺少固定客户端不得静默跳过。常规无凭证后端CI可运行结构/实际socket回归；实际客户端分发不可靠时不伪造CI客户端兼容通过。提交后集中review，相关修复回归；阶段出口完整后端与Linux定向协议检查，不重复无变更前端全集。
