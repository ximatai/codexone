# 首页输出吞吐

此为 v0.26.12 的历史口径，后续口径见[请求输出速率](../request-output-rate/proposal.md)。

首页在途请求区展示近 60 秒已结算的主模型输出 Token 除以有正输出结算的秒数，单位 Token/s。沿用日用量主模型输出字段，图片渲染和 SVG 作者的独立字段不计入。每次首次凭完整证据结算计入一次，重复或修订不重复累计，尚未结算的流式输出不估算。

在 SQLite 事务成功后写入固定 60 个秒槽和近 7 个业务日的计数。日趋势按同一口径，历史日用量不回填。统计在进程内维护，与浏览器订阅无关，重启从空窗口开始。通过现有概览 inFlight 区段的可选字段推送，窗口自然衰减。断开推送或连接旧版后端时显示未知。无数据库迁移，旧版前端可忽略新字段。
