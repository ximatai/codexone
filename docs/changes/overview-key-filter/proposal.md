# 首页 Key 筛选

按用户确认的展示规则，归档 Key 不进入汇总，默认“今日活跃”（UTC 当日准入数大于零），可切换“全部”（全部未归档 Key）。停用但有当日请求的 Key 仍保留，并标注已停用。

依据 A19 与 U10；首页显式请求 includeArchived=false，在 SQL 分组及容量限制前过滤归档记录；默认查询仍包含归档 Key，供密钥管理读取今日 Token 与最近使用时间。历史 options、逐笔记录和总量不变。摘要新增 enabled 字段，无 schema 变化；旧前端忽略新增字段，回退不改变持久数据。

验收覆盖归档且当日有请求、停用但活跃、零请求、空态与大屏/窄屏切换。使用独立合成本地环境供人工验证。

密钥管理默认筛选“可用”；“全部”并行读取未归档/已归档两套既有分页接口，任一失败不发布部分列表，按 ID 去重。显式 status=all 保留全部筛选，缺省为 available；归档/恢复在全部范围内保留行，筛选不会改变密钥授权与用量。
