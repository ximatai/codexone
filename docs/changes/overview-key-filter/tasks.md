# Key 筛选任务

实现首页与密钥管理各自的筛选范围，保留归档用量并供本地人工验证。

- [x] 首页默认今日活跃，可切换全部未归档 Key，停用状态明确标注。
- [x] 摘要 API 按 includeArchived 筛选，密钥管理保留归档 Token 与最近使用。
- [x] 密钥管理默认可用，全部合并未归档与归档分页；任一读取失败不发布部分列表。
- [x] 同步规范和指南，运行定向回归并启动本地合成服务。
- [ ] 用户本地页面复核。

验证平台为 macOS arm64：2 项 Swift keyUsage 测试、管理 HTTP 实进程与非法筛选参数验证通过；前端 206 项单元测试以 `--maxWorkers=2` 通过（默认并发曾超时）；Chrome 验证首页筛选、空态、密钥默认可用/全部/归档和刷新保持，覆盖大屏与窄屏。构建、类型、lint、格式及文档检查通过。合成实例含今日活跃 2 条、未归档 4 条、归档 1 条，密钥管理全部共 5 条；未部署生产。
