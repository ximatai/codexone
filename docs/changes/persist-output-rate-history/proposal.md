# 请求输出速率历史恢复

首页近 7 天趋势跨重启保留。沿用现有请求速率口径，在首次符合条件的结算事务内，把结算秒与冻结后的速率写入 `attempts` 的两个可空字段。新增部分索引用于启动时按业务日恢复最近 4096 笔，每次最多读 7 个业务日。近 60 秒读数只使用当前进程的结算，前端和 WebSocket 字段保持原契约。

schema 升到 v13，生产升级需先停服备份并显式迁移。旧记录无样本，不作估算回填。旧二进制无法打开新库，回退使用升级前完整备份。
