# 账号停用与强行停用

账号卡片使用二态开关。关闭开关立即禁止新派发（包括续接），已经准入的请求继续完成。等待期间显示进程内的请求数，并允许管理员在确认后取消这些请求。历史 draining 仍可按原规则续接，详情可显式切换启停。

计数覆盖网关管理的生成、预热、压缩、图片和转发辅助请求。已结束请求、空闲连接、额度/授权管理和历史未知执行不计入。强行停用校验账号修订与 disabled 状态，只向当时选中的进程内请求发送取消，沿用既有结算、未知责任和禁止重放规则。网关无法确认上游是否已停止。

验收在合成环境检查正常结束、强制取消、陈旧操作隔离和桌面/窄屏交互。无 schema 或配置迁移，回退后已停用账号仍为 disabled，取消过程不跨重启恢复。
