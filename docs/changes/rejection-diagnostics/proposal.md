# 准入拒绝下钻与客户端协议回归

首页拒绝计数打开同一业务日的只读诊断。沿用现有用量查询分页，只显示准入前拒绝；每条记录新增固定子原因和入口阶段。复用现有协议分类，禁止持久化请求正文、参数值、上游文本及凭证。老记录不推断子原因。

schema v14 为拒绝记录增加可空列。v13 普通启动遵循现有自动迁移的实例锁、私有备份和事务门禁；v12 保留原有升级路径。旧二进制回退使用升级前完整 bundle。对照[用量规范](../../reference/specs/usage.md)和[运行规范](../../reference/specs/operations.md)。

协议回归重点覆盖长连接上的停用或换证、客户端转 HTTP 和会话预算终态。保持既有的执行归属与未知执行语义。
