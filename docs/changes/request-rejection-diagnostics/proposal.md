# 建执行前拒绝的脱敏诊断

依据O07及数据面失败/无重放约定，真实客户端已完成WS认证升级却在建执行前结束，HTTP回退400；现有持久拒绝账不覆盖解析失败，通用提示无法定位。补齐首条WS解析失败的标准error帧，随后关闭；不创建执行、不打开上游、不改变字段/权限限制，不自动重试。

协议错误响应时使用swift-log记录固定允许列表中的错误码、HTTP状态和本服务生成的UUID（非指标label），其他码归other。不打印Error描述、正文、字段名/值、Key、路径、上游响应或客户端stream_id；进程全局每分钟最多16条，超过直接丢弃，不排队。保留持久拒绝账与unknown语义。未知首条lane不回显。

验收：真实HTTP/WS失败码及明确首帧拒绝；无上游/无执行、敏感合成正文不入日志、固定允许列表与采样上限；正常协议与原有失败回归。主Agent实现/定向验证后提交集中review，再同源码Linux检查和新候选更新，仅独立合成服务；由用户再操作定位具体协议差异。Desktop兼容在成功前不关闭。
