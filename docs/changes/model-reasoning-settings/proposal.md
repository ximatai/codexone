# 已启用模型的推理设置

模型目录支持在启用状态下设置默认推理档位和允许范围。默认值可跟随模型资料，也可从允许范围选择。范围必须是模型声明档位的非空子集。收窄范围后，客户端须显式发送允许的档位，网关在转发前拒绝缺失或越界档位。目录公布的默认值供客户端选择，网关保持请求参数透传。

Key 的档位权限继续生效，客户端可用范围是两层权限的交集。模型级变更不改写既有 Key，交集为空时该 Key 的客户端目录不再列出此模型。图片专用模型沿用现有能力。

设置与目录 revision 一起持久化，既有目录沿用原行为。schema v18 让不识别设置的旧程序拒绝打开升级后的数据库。重新启用时如新资料不兼容，要求明确确认重置推理设置。

规范见 [管理面](../../reference/specs/control-plane.md)。验收覆盖生效目录、请求权限、持久化和桌面及窄屏表单。
