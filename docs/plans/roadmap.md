# 实施目标

路线以可验收闭环推进，可按依赖和新证据调整；不记录当前进度。

| 阶段 | 交付目标 | 验收重点 |
|---|---|---|
| 持久执行基础 | Swift 包/进程、SQLite、准入/绑定/结算 | 事务竞争、ID 暴露屏障、未知执行重启恢复、任务结束 |
| 协议与账号池 | HTTP/SSE/WS、订阅授权/刷新、多身份 | 客户端契约、懒绑定、隔离、取消/重试边界 |
| 图片与恢复 | 原生 Images、统一权限、限期加密缓存 | 实际产品入口、可用恢复路径、不重执行、容量/删除/代际 |
| 管理闭环 | 初始化、账号、Key/策略、诊断/核对 | API/前端契约一致、完整管理流程 |
| 可发布首版 | Linux amd64 OCI/Compose、升级/备份/恢复 | 无凭证 CI、显式 live 验证、资源回稳、可追溯回退 |

内部单身份切片不缩减首版多账号/Key 目标。重型缓存之前验证客户端恢复方式；不可行时及时沟通，不能把保存正文等同于交付恢复。
