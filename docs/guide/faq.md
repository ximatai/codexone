# 常见问题

定位接入、账号和用量问题，优先核对可观察状态。

## 为什么 ready 返回 503？

没有启用且授权有效的账号、存储故障或安全门禁都可能导致未就绪。先看管理台提醒；liveness 只证明进程存活，不证明可以生成。

## 为什么看不到模型或图片工具？

核对配置模型与 Key 授权交集。用 Key 接入的客户端可能使用内置目录，修改 provider 后彻底退出 Desktop 并新开会话。生图门控头只控制客户端工具声明，实际权限仍由网关验证，见[客户端配置](client-setup.md)。

## 为什么费用或 token 显示未知？

缺少可信终态/用量、断线和超时可能留下部分或未知用量。未知不计零，不自动重发；估算费用与订阅窗口额度是不同口径，不用于对外结算。

## 能否恢复断线前的全部输出？

当前没有面向客户端的正文/图片恢复缓存，不能承诺重启或断线后重读输出。原生 WS 短暂续读终态用于结算，不代表客户端已收到。旧会话无法续接时可新建会话；不要盲目重复有工具副作用的操作。

## 能否多人共用订阅或作为公共 SaaS？

项目定位是个人自托管：管理自己的订阅账号，为自己的设备和工具分配 Key。它不提供订阅共享授权、计费支付、多管理员 RBAC 或多节点高可用。

## 是否官方集成，能否避免账号风控？

这是独立非官方项目，无 OpenAI 隶属或背书。网关使用 Codex 官方客户端标识与官方 OAuth 客户端 ID；这可能违反提供者条款、触发风控或导致账号受限，协议也可能变化。兼容成功不代表获得授权。

## 如何报告问题？

普通问题用合成复现提交 Issue；漏洞通过[安全政策](../../SECURITY.md)中的私密入口。不要上传凭证、授权文件、回调、数据库、正文或日志原文。
