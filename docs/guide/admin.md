# 使用管理面板

管理自己的订阅账号，并为自己的设备和工具分配独立 Key。

## 前提

完成[配置](configuration.md)与 HTTPS 反代；从私有 `secrets/admin` 文件取得管理员秘密，用户名为 `admin`。管理员秘密与数据面 Key 不通用。

## 概览与账号

首页“今日 Key 请求汇总”显示业务日内有准入请求的未归档 Key，按已观测 Token 降序排列。点击失败率可打开对应 Key 的当日失败明细。归档 Key 的历史可在用量中查看。

首页展示准入量、Token、生图张数、失败率、在途请求及已结算请求的端到端输出速率中位数。右栏显示订阅额度、运行资源及需要关注的事项。额度来自提供者观测，使用比例与时间参考线可用于比较当前消耗进度。未结执行的提前释放入口位于“用量与诊断”。

进入账号页开始授权，默认显示设备码、验证链接与倒计时。复制设备码，在自己的浏览器打开验证链接并登录、输入设备码；弹窗自动显示授权结果。初次账号默认禁用，核对后点击弹窗内的“启用”，这是独立操作。重新授权也默认使用设备码，保留原账号身份和策略。

设备码登录不可用时，可检查 ChatGPT 安全设置是否已开启设备码登录，或点击“改用浏览器回调方式”。备用方式在新窗口登录后，把最终 localhost 回调地址粘贴回管理面板；即使回调页无法连接也可复制地址栏。远程服务器不占用你设备的 localhost 回调端口。不要公开设备码、回调、授权 URL、token 或浏览器截图。关闭或离开授权弹窗会取消流程，到期或失败后须重新发起，不会自动重试。

需要重新授权时使用账号详情中的操作。临近到期会后台提前刷新；`requires_auth` 需要重新授权，`auth_uncertain` 不能靠反复刷新解除。禁用/排空和授权状态分别管理，刷新不会自动启用账号。

## 访问密钥

访问密钥默认展示“可用”；筛选“全部”包含未归档与已归档 Key，“已归档”可单独查询归档记录。

为每台设备或每个工具创建独立 Key，使用不含个人信息的主体标识和方便辨认的显示名。创建/轮换后的秘密只展示一次，关闭或离开后无法取回；遗失时核对元数据后显式轮换。轮换保留 ID、归属与用量计数。

对话和图片分别选择“全部模型”或“指定模型”。全部模型跟随启动配置，配置新增模型会扩大该范围；指定模型保持显式清单。视觉输入与图片生成是独立开关，关闭生图不影响已授予的视觉输入。图片工具还需对话模型和图片模型同时获准。

限额可填写数值或选择不限；不限仍受账号并发、容量和存储保护。禁用阻止新的执行，已准入请求继续结算。归档先禁用并隐藏在默认列表中，不删除历史用量；通过已归档筛选恢复后仍为禁用，需要再次显式启用。已归档 Key 不能直接修改或轮换。

## 用量与失败处理

按 Key、时间、模型和错误筛选请求，查看完整/部分/未知用量、估算费用和推理强度。未知不等于零消耗；断开客户端也不证明上游停止。修改结果未知时先刷新核对，界面不会自动重发。冲突后先读取最新版本再编辑。

管理员会话空闲 24 小时或最长 7 天失效，服务重启会清除会话。浏览器不保存秘密到 localStorage/sessionStorage。

## 重置卡

账号详情的“重置卡”实时读取可用记录。点击指定卡片的使用按钮后，核对卡名/到期并确认。当前没有可重置的用量时，卡未消耗。结果未知时用“核对上次操作”确认核对，系统沿用原请求编号；不要改选卡或猜测重试。

“到期前自动使用”默认关闭，可按小时和分钟设置提前量（1 分钟至 24 小时，默认 24 小时），失败重试 0—5 次（默认 3）。提前分钟数须至少为重试次数加 1。每 30 分钟读取已启用且授权正常账号的卡片，到点单独唤醒并重新读取，每轮最多一张最早到期卡，无到期时间的卡不自动使用。失败后每隔 1 分钟重试，绝不会在到期时或到期后使用；未知结果沿原请求编号，预算耗尽后保留人工核对。当前无用量可重置不占失败预算，下个常规周期可再试。手动使用不会自动重试。成功、未知结果及重试耗尽会在首页提醒并显示失败尝试次数。恢复备份后该开关关闭，先人工核对上游记录和未知操作再决定开启。此操作不清本地 Key 用量，也不提供官方客户端菜单透传。


账号详情的“空闲窗口预热”默认关闭，可选择当前配置的对话模型并编辑 1—200 字符纯文本（默认 hello）。默认模型按本地输入与输出费率之和最低、同价按 ID 排序；不保证真实订阅成本。确定 5 小时或每周窗口空闲后只发一条合成请求，并记录内部用量；字段未知不发送。模型移除或连续三次失败自动关闭并提醒。重启不会重复预热；发送后须先观察到窗口活跃并等待该窗口到期。推理和输出参数固定且不可调高；订阅接口不支持输出 token 硬上限。合成流量会消耗额度，并可能增加提供者风控或账号受限风险；请自行决定是否启用。

## 今日 Key 面板

首页只列当前业务日有准入的未归档 Key，最近活动倒序。名称可点击查看完整主体、ID 与精确计数；停用、执行中、取消及结果未明保留显示。失败数跳转该摘要日期的精确失败记录，不含准入前拒绝。至少 20 次请求、5 次失败且失败率至少 20% 时标橙色。

Token 与每日限额同口径，缺证据显示已观测下界。缓存命中率按已观测输入加权，失败/取消而无用量的请求排除，提示会说明缺失；没有观测输入时为“—”，真实零命中为 0%。统计日期取服务器业务日，Key 到期仍用 UTC。

## 可选首页实时概览

完整验收前默认关闭；部署开关和代理配置见[TLS 反代](../operations/tls-proxy.md)。实时路径只读，仅首页及其账号抽屉订阅；隐藏、暂停或离开首页就断开。页面显示实时/连接中/轮询/暂停和各源成功时间；轮询不提供最近结束活动。最近结束仅保留进程内短期观察，完整历史仍看用量页。账号额度继续来自既有被动观察，不增加提供者请求。写操作与未知结果核对沿原流程。
