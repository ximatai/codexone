# 产品范围

日期：2026-10-21。已确认边界；细节实现以能力规范及架构为准。

CodexOne 面向自行管理上游订阅账号和下游 Key 的自托管使用者，首版为单管理员管理域。通过多个稳定使用主体（principal）支持 Key 轮换、权限隔离、用量治理和诊断，不首发公网多租户 SaaS。

## 首版闭环

- 安全初始化、管理登录、导入/授权受支持订阅账号、刷新与失效诊断。
- 多账号调度、多主体/Key、对话模型范围与独立图片生成权限。
- Codex HTTP/SSE/WS、客户端函数工具、经验证的压缩续接、独立 Images generation。
- 请求/并发硬限制，token/图片治理与金额估算；兼容优先，披露未知及可能超额，不承诺数值绝对封顶。
- 有上限、有期限的正文/图片恢复缓存；加密、隔离、删除，不自动重执行。
- 管理诊断、账本与未知执行核对、升级、备份恢复和回退。

## 首版排除

支付/收费结算、多管理员权限体系、SaaS、多节点/HA、Redis、通用插件、完整聊天历史托管、图片相册、文件资产服务、图片 edits、未经验证的远程工具及后台执行。公开 API 项目 Key 后端后续独立适配。

## 成功标准

普通使用者完成初始化至文本/工具/出图闭环；管理员能解释账号选择、限流、断流、未知消耗及恢复结果。不同主体/账号对象不串用；故障不导致静默重复执行或用量丢失；本地资源有界且可回收。通过弱服务器档位 Linux 长时与故障测试后才公布容量，不宣称语言或框架天然更快。
