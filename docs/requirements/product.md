# 产品目标与范围

共识是推进依据，可依据实际困难或新证据与用户沟通调整，不视为永久业务边界。

## 服务对象与价值

开源、自托管 Codex/Responses 协议网关。面向自行管理订阅上游和下游 Key 的使用者，提供稳定接入、账号池、身份隔离、用量解释和故障恢复。

## 首版目标

- 单管理员域、多上游账号、多 principal/Key；订阅账号池优先。
- 文本、客户端函数工具、经验证的压缩续接与原生图片生成。
- 对话模型与图片生成权限分开，关闭生成不误伤视觉输入。
- 请求/并发硬限，兼容优先用量治理，金额估算并披露可能超额。
- 限期限量、加密隔离的正文恢复缓存，不自动重新执行模型或工具。
- 安全初始化/授权、账号/Key 管理、诊断/核对、升级、备份恢复和回退闭环。

## 聚焦范围

首版不承担支付/严格收费、多管理员 RBAC、公网 SaaS、多节点 HA、永久历史/相册、通用文件服务或未验证的后台/远端工具。公开 API 上游、图片 edits 等扩展以后按需求评估。

## 验收目标

使用者完成文本/工具/出图闭环；管理员能解释权限、调度、用量与恢复结果。主体与账号不串用，本地资源有界，失败不导致静默重复执行或用量丢失。缓存必须对应实际可用且明确说明的客户端恢复方式；具体接口未验证前不承诺兼容。详见 [规范](../specs/README.md)。
