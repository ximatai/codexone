# ADR 0002：兼容优先资源治理

工作方案：provisional（可按新证据修订）。日期：2026-10-21。来源：用户明确选择。

决定：请求/并发硬限，token/图片按已知用量治理，金额估算。允许正常 Codex 续接、图片与工具；可信最坏消耗 U 为可选证据，不是通用启用门槛。限制未知执行数量与预留，超预算停止新准入。

原因：订阅后端的隐含历史、推理与图片不总能证明完整消耗上界；按严格成本证明禁用会妨碍首发核心用途。有限执行数量不能证明真实 token/金额数值封顶，界面必须准确披露。

代价：可能超额和未知消耗由管理域治理。断线/过期不自动退款；管理员需审计核对。首版不提供严格收费账本或硬金额保证。
