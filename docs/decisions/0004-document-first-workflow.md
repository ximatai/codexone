# ADR 0004：正式目录与可交接文档治理

工作方案：provisional（可按新证据修订）。日期：2026-10-21。

决定：正式项目在用户指定的新目录独立建立，迁入架构及无秘密验证参考，不复制实验源码、运行日志、真实图片或凭证；仅精选脱敏报告作证据。初始化独立本地 Git，不预设远程承接。Markdown 需求、能力规范、ADR、变更提案、STATUS/HANDOFF 构成治理入口。

原因：实验限制和未实现能力不应成为产品默认；新 Agent 应仅依赖仓库文件即可判断事实并继续。远程承接需要独立确认，不能自动把原型代码和 CI 当作产品基线。

代价：首次需要建立正式包/前端/CI，历史证据必须标明适用范围；不以占位代码或空壳 CI 宣称产品已运行。未来采用 OpenSpec 等工具须保留可读需求与追溯链。

2026-10-21 修订理由：用户要求全局状态只在 STATUS，README 不维护阶段；全部业务边界为可演进草案，困难/更优方案及时沟通。稳定入口只保留职责与链接，规范独占行为细则。
