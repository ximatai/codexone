# ADR 0004：正式目录与可交接文档治理

状态：accepted。日期：2026-10-21。

决定：正式项目在用户指定的新目录独立建立，迁入架构及无秘密验证参考，不复制实验源码/产物/凭证。初始化独立本地 Git，不预设远程承接。Markdown 需求、能力规范、ADR、变更提案、STATUS/HANDOFF 构成治理入口。

原因：实验限制和未实现能力不应成为产品默认；新 Agent 应仅依赖仓库文件即可判断事实并继续。现有远程仓库仍是实验项目，自动推送或覆盖会混淆历史。

代价：首次需要建立正式包/前端/CI，历史证据必须标明适用范围；不以占位代码或空壳 CI 宣称产品已运行。未来采用 OpenSpec 等工具须保留可读需求与追溯链。
